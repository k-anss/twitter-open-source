# 按键与实测

| 键 | 动作 |
|---|---|
| 语音长按 | Fn 按住、遥控器收音；松手后豆包识别，文字稳定约 1.5 秒自动发送 |
| ↑ / ↓ | 滚动对话，支持长按 |
| ← / → | Shift+Tab / Tab，移动控件焦点 |
| 中间确认 | 当前按钮执行；否则 Return |
| ＋ / － | Command+Option+Left / Right，上一个/下一个任务 |
| 🏠 | 已运行时激活 Codex，并聚焦唯一可用输入框；未运行时先启动，启动完成后再按一次 |
| 返回 | 关闭弹窗；有唯一停止按钮时停止；否则 Esc |
| ≡ | 定位唯一“允许一次”按钮，无请求时提示音 |
| TV 长按 ≥1 秒 | 只执行当前唯一“允许一次”；短按不批准 |
| 电源 | 暂停/恢复遥控功能，提示音 |

除主页/电源外，非语音快捷操作仅在 Codex 前台执行。暂停也会停止遥控语音处理。左/右是控件导航，不是文本光标左右移动。

分轮测试，每轮检查日志和用户可见结果：
1. 语音说“自动发送测试”，松手不再手动点发送；要求日志出现 `[SEND] ...已发送 Return`，且消息确实到达。
2. ↑↓、←→、🏠；确认光标回输入框。
3. 输入“确认键测试”按中间键；再 ＋/－切任务并返回。
4. 打开菜单按返回；按 ≡ 看能否找到真实授权或发出无请求提示。
5. 电源暂停后 ↓不滚动，再按电源恢复后 ↓滚动。
6. 用一个用户已请求的低风险操作获得真实授权框，例如创建下载文件夹里的专用测试文本；请求精确文件路径权限。保持 Codex 前台，持续按 TV 约 2 秒再松开。日志应出现“长按计时完成”“允许一次 result=0”，并由权限工具确认已授予，再执行操作。拒绝或权限未授予时不写文件、不宣称通过。完整访问模式没有对应授权框，不能靠削弱安全策略完成测试。

2026-09-25 在原机上述按键完成实测；TV 成功按住 1200ms。新机器、其他固件、其他 Codex 语言或新版界面须重新测试，不能继承原机验收结论。返回键关闭菜单已测，所有可能的停止/弹窗场景未逐一覆盖。
