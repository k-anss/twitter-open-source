# 故障诊断

日志：`~/Library/Logs/MiRemoteBridge/MiRemoteBridge.log`。只取本次测试的末尾片段；不收集全部用户数据。

- 输入中文失败：先停桥接，确认系统真正选中的输入法。Shift 只改变当前输入法状态，不会从微信切到豆包。查看豆包拼音设置，必要时只移除/重新添加豆包输入源。重装后系统可能需要重启；先让用户保存工作，不重复卸载。不能用粘贴中文证明拼音引擎正常。
- 一台机器出现两份 DoubaoIme 进程：核查可执行路径。不要把更新缓存里的 `.app` 作为可运行备份；压缩保存，避免 Launch Services 启动备份应用。保留正常安装目录，不自动重设账号。
- 语音无反应：先看 `[KEY] voice-key DOWN`、`Fn DOWN` 与 `AUDIO_SUMMARY`。无 HID→检查连接/输入监控；无 Fn→检查辅助功能与暂停状态；有音频无文字→核对豆包 Fn 和 MiRemoteV 2ch、麦克风权限。Mac mini“找不到内置麦克风”不影响遥控器长按收音。
- 自动发送失败：`当前不是可读取的 Codex 输入框` 表示没获取文本，不能用固定延时盲发替代。源码已请求 Electron AXManualAccessibility；该属性可能返回 unsupported，但后续读取成功仍可发送。更换焦点会主动取消。让用户点输入框重新测试。
- ＋/－无动作：当前实现直接触发已核对的 Command+Option+Left/Right。检查 Codex 是否在前台以及用户是否改了快捷键；不再依赖旧“Previous Task”菜单名称。
- 主页：看“无法读取前台窗口”“输入框不唯一”等日志。只定位唯一文本输入框；不要凭屏幕固定坐标点击。
- TV：先找“已找到允许一次”，再看“松开，持续毫秒”。低于1000ms本来就不会批准；需要真正持续按住。HID 松开依据 element cookie，避免把其他数组元素的空值当成同一键松开。`result=0` 仅表示 AX 操作成功，最终仍要核查工具授权结果。无唯一按钮时检查语言/新界面，保留“允许一次”范围，不改成任意允许按钮。
- 无权安装/停止：先完成包内构建、校验，再按当前工具允许的方式请求所需路径；无法停止时让用户从菜单退出。不要删除运行程序后任其缺失，不反复触发已被拒绝的操作。

源码重建：`cd source/bridge && ./package-app.sh`；`./run-self-tests.sh` 检查 ATVV 音频流边界。自检不包含物理按钮/真实授权。SwiftPM 若嵌套 sandbox_apply 失败，可使用 SwiftPM 的 `--disable-sandbox` 仅关闭包构建自己的嵌套沙盒，仍遵守外层权限；缓存放可写临时目录。更新程序保持 bundle ID 与 designated requirement，仍需验证系统权限。
